macOS 系统通知交互

侧边系统消息提醒（Web 高保真）

体验分析：参考 macOS 通知中心，新消息从屏幕右上角滑入，不打断当前浏览；悬停显示关闭，点击横幅进入通知中心或业务页；多条通知纵向堆叠，超出自动收起最早一条。 开发约定：调用 FL_macNotify({...}) 或预设 FL_macNotifyPresets.tip()。

交互规格（可直接对接开发）：
1. 入场动画：自右向左滑入 + 淡入，时长约 420ms，缓动 cubic-bezier(0.22, 1, 0.36, 1)
2. 退场：滑出右侧；默认 5.5s 自动消失；悬停显示左上角关闭钮
3. 点击卡片主体 → 跳转 href；操作按钮独立触发且不冒泡
4. 最多堆叠 4 条；毛玻璃背景 + 圆角 14px，贴近 macOS Sonoma 通知样式
