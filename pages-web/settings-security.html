双因素验证 (2FA)

验证登录者与修改登录密码时的操作身份

To 研发 常用设备免验证；新设备 / 异地 / 超 30 天未登录或改密时须输入动态码 或者生物识别

开启后，常用设备上的日常登录流程不变（邮箱 / 密码即可）。仅在风险场景或敏感操作时，才要求第二因素校验。

  • 认证器 APP：推荐首选。触发场景包括：新设备或新浏览器首次登录、异地 / 异常 IP 登录、超过 30 天未登录、修改登录密码等账号安全操作
  • 生物识别：通过 WebAuthn 绑定本机指纹 / 面容，在已信任设备上可快捷完成上述校验
  • 与提现安全：2FA 证明「是你本人」；支付密码、邮件确认等控制资金转出流程——链上提现时依次校验

关闭认证器 APP？

关闭后，以下场景将不再要求输入认证器动态码，账号安全强度会下降：

  • 新设备 / 新浏览器登录
  • 异地或异常 IP 登录
  • 超过 30 天未登录
  • 修改登录密码等敏感操作

如仅更换手机，建议在新设备添加密钥后再关闭，或改用生物识别作为补充。
