大额提现冷静期

平台级策略，由运营后台统一配置，用户端不可自行开关。单笔提现达到阈值后延迟到账，期间用户可在 C 端撤销。

修改提现地址冷却期

用户新增或修改提现地址后，在冷却期内禁止向该地址发起提现；冷却从地址保存成功时刻起算。平台级策略，用户端不可自行开关。

异常 IP / 异常设备登录后提现限制 To 研发 判定 异常 IP / 异常设备 · 判定逻辑（研发对齐）

异常 IP：本次登录 IP 满足任一条件即命中——① 不在该 UID 近 30 天「成功登录常用 IP」集合；② 与上次成功登录 IP 的 geo（国家/省）发生突变；③ 命中代理 / IDC / 黑名单 IP 库。

异常设备：本次登录设备指纹（Device ID）满足任一条件即命中——① 不在该 UID 已信任设备列表；② 账号首次出现的新设备；③ 环境异常标记（模拟器 / 篡改等，若客户端有上报）。

限制生效：登录成功且判定为异常 IP 或 异常设备后，自该次登录起进入限制窗；窗内禁止发起提现（接口直接拒绝）。限制时长取本页「限制时长」配置；用户完成二次验证并加入可信设备/IP 后可提前解除（产品可选，需研发确认）。

存储建议：登录态写入 last_login_ip / device_id 与异常标记；提现下单前校验 withdraw_lock_until。

检测到异常 IP 或异常设备登录后，在限制时长内禁止该用户发起提现。判定细则见旁侧「To 研发」玻璃批注。
