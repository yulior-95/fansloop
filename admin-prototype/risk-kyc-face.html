KYC 身份证人脸匹配分值

机审 API 对人脸快照与证件照比对后返回 0–100 匹配分值，后台按以下阈值自动分流。 映射 PUT /api/v1/admin/kyc-face-match-config；审核流水见 KYC 审核记录。

分值阈值
人脸分值 ≥ 此值时，机审直接通过，无需人工
分值处于 [人工审核分数, 直接通过分数) 区间时转人工队列

机审分流规则（原型）
  1. 用户提交证件 + 人脸后，Verify API 返回人脸匹配分值（如 78.5）。
  2. 分值 ≥ 直接通过分数 → 机审通过，用户端同步为已认证。
  3. 人工审核分数 ≤ 分值 < 直接通过分数 → 记录状态为「待审核」，进入人工队列（非 API 异常）。
  4. 分值 < 人工审核分数 → 机审自动驳回，回传拒绝原因。
  5. 若 API 超时/异常未返回分值，运营可在审核详情中人工介入通过或驳回。
