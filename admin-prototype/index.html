系统设置 · RBAC 高保真原型

角色管理、成员账号、操作日志三页独立 HTML，以 iframe 平铺展示，可直接用于前端开发对齐。技术栈：Ant Design 4 CSS + 自有壳层 admin-shell.css + 共享模块 js/settings-rbac.js。

1. 用户体验分析

核心用户

超级管理员、运营主管、风控专员——需在 Web 后台完成权限分配、成员生命周期管理与操作审计。

核心诉求

  • 角色权限粒度清晰，按菜单层级勾选
  • 成员创建简单直接，IP 风控与角色一次配置
  • 操作可追溯，模块/动作可检索

交互原则

  • 列表页只做浏览与入口，复杂表单走弹窗
  • 敏感写操作统一谷歌验证二次确认
  • 创建成员无需邮件邀请，即创即用

2. 信息架构

角色管理

列表：角色名称 · 创建时间 · 更新时间 · 操作。弹窗：权限树（一级菜单 → 二级菜单 → 功能操作）+ 备注 + 全选/全不选。

成员账号

列表含序号、账号、绑定 IP。新建/编辑弹窗合并角色分配：账号*、IP*、角色*、状态*、邮箱（选填）、显示名称（选填）。

操作日志

按一级/二级模块、功能操作、结果筛选；详情展示 Request ID、UA 与变更快照。
