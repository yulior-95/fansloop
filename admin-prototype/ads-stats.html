广告数据统计

平台侧汇总曝光 / 点击 / CTR / 消耗 / 转化。汇总维度默认「全部广告 · 累计」；明细按单条广告下钻。正式环境按日汇总；原型为种子累计值，周期/来源筛选未接数。

总曝光 含义：广告进入可视区并满足曝光条件的次数（有效曝光）。
维度：广告 ID + 日；本卡 = 所选范围内各广告合计。
公式：Σ stats.impressions。
异常：风控标记为异常流量的曝光不计入有效值（正式）；原型种子未扣减。
可采集：客户端可视曝光埋点（≥50% 面积、≥1s 等）上报 adId/slot/uid/ts；日频控只限展示，不改此计数口径。
—
总点击 含义：用户点击广告可点击区域（Banner / 信息流卡 / CTA）的次数（有效点击）。
维度：广告 ID + 日；本卡合计。
公式：Σ stats.clicks。
异常：同会话短时连点合并；风控异常点击不计入有效值（正式）。原型为累计种子。
可采集：点击事件埋点上报 adId/slot/landingType/ts；与曝光共用归因 ID。
—
CTR 含义：有效点击率。
维度：与汇总曝光/点击同一筛选范围；明细表按单条广告算。
公式：有效点击 ÷ 有效曝光 × 100%；曝光为 0 → 0%。
异常：分子分母均用「有效」口径，异常流量两边都不进。
可采集：派生指标，无需单独埋点。
—
总消耗 USDT 含义：已从「冻结」结转为「已消费」的广告费用（USDT）。
维度：订单 / 广告；本卡按广告 stats.spend 合计（应与账变对齐）。
公式：Σ 已结转金额；一口价按排期结束/下架/退款结算，不按曝光·点击计费。
异常：退款成功回冲消耗；风控暂停不自动结转。
可采集：以资金账变 type=spend/refund 与订单冻结字段为权威源；非客户端行为埋点。
—
转化 含义：点击后、带广告归因的目标达成次数。
维度：广告 ID + 日；本卡 Σ stats.conversions。
一期可追踪事件：creator→到达主播主页 PV；external→外链跳出成功。进直播间归因窗口待业务确认。
异常：异常点击链路下的转化不计。
可采集：落地页/主页打开须带 adId；原型为模拟数，正式勿当真实转化。
