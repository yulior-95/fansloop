积分活动类型

内置类型覆盖任务、邀请、签到、兑换等；运营可新增自定义类型并配置 schema 字段，创建活动时自动加载对应表单项。 获取类类型会同步出现在 积分风控 → 积分冷静期 配置表；兑换商品等消耗类不参与冷静期。 映射 GET/POST /api/v1/admin/points-activity-types。

类型标识 IDSchema 字段来源操作

运营可配 vs 需研发接入

活动类型运营能否独立创建说明
计时任务 / 签到 / 邀请 / 互动 / 订阅可以触发条件为内置埋点或标准玩法，后台改参数即可生效
研发活动 / 研发接入兑换参数可配研发创建并绑定编码；运营可改时效与业务参数（如加速 24h→32h），不可新建玩法或改编码
兑换商品 / 转盘可以消耗类，规则固定；复杂抽奖逻辑仍可能需要研发
自定义类型表单占位Schema 仅生成表单项，C 端发奖逻辑默认未实现
