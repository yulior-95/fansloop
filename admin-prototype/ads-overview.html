广告概览

关键指标、近 7 日趋势与来源结构。对接 API 后替换 FLAdStore.adminOverview() 返回值即可。

广告总数 公式：广告库条数合计（含用户已删除留档）。
口径：不区分上架审核 / 投放状态，后台可见全量广告。
—
待审核 公式：上架审核 = 待审核，且投放 ≠ 已下架 / 已结束。
口径：仅统计上架/内容审核队列；不含退款审核单。
—
投放中 公式：投放状态 = 投放中（含历史 active）。
口径：须已上架审核通过且在排期内正在展示；不含暂停 / 待开始 / 已结束 / 已下架。
—
今日曝光 公式：今日有效曝光次数之和（同用户同广告受日频控去重后计数）。
原型：≈ Σ(广告累计曝光) × 8% 模拟「今日」切片；对接后按自然日 UTC+8 汇总 recordImpression。
—
今日点击 公式：今日广告 CTA / Banner 有效点击次数之和。
原型：≈ Σ(广告累计点击) × 6% 模拟今日；正式按自然日汇总 recordClick。CTR ≈ 今日点击 ÷ 今日曝光。
—
今日消耗 (USDT) 公式：今日从冻结转入已消费的 USDT（一口价套餐按排期进度结转，非按次扣费）。
原型：≈ Σ(广告 stats.spend) × 5% 模拟今日；正式取财务流水 type=spend 且自然日匹配的金额合计。
