GOODFANS 双商城运营 · 高保真原型

本入口以 iframe 平铺 嵌入全部独立页面（不跳转）。目录： admin-prototype/mall-hifi/。 页面含 Header / Sidebar / Main / Footer，右侧常显「To 研发」玻璃批注，预留内容区不被遮挡。 可直接用于开发对齐。

1. 用户体验分析

核心用户

  • 运营审核：处理数字商品上架前合规
  • 运营管理：全量商品生命周期与强制下架
  • 财务运营：核对数字成交与联盟佣金分账

核心需求

  • 待审队列可快速通过 / 驳回（驳回原因必填）
  • 状态可筛选，封面可识别素材类型
  • 分成结果可追溯（平台费 / 创作者实得）
  • 联盟分类可启停，影响选品库导航

核心交互逻辑

创作者提交→ 审核队列→ 上架 / 驳回
C 端购买→ 数字销售记录
第三方成交回传→ 联盟佣金分账

2. 产品界面信息架构

数字商城（3 页）

  • 数字商品审核 — 图片合集 / 视频作品队列
  • 数字商品管理 — 全状态商品台账
  • 数字销售记录 — 平台内成交明细

联盟商城（2 页）

  • 实体商品分类 — 选品库导航配置
  • 联盟佣金流水 — 第三方回传分账

统一壳层规范

  • 左侧模块导航 · 顶栏面包屑与操作
  • 主区：说明条 → KPI → 工具栏 → 表格
  • 页脚：接口映射提示（研发对齐）
  • 右侧：常显玻璃批注层（不被遮挡）
