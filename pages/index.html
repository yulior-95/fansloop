可点通的完整流程

  1. 创作者：我的 → 我的橱窗 → 创建数字商品 → 提交 → 管理（置顶/下架/上架/强制下架提示）→ 预览访客 → 实体选品库加入
  2. 买家（余额足够）：Creator Store → 图片详情 → 确认订单 → 输 6 位密码 → 成功 → 已购解锁
  3. 买家（余额不足）：图视包详情 → 确认订单（或点「模拟余额不足」）→ 去充值 / 模拟充值后继续 → 密码 → 成功
  4. 已拥有：访客橱窗点「已拥有」卡片 → 详情禁用购买 → 打开作品

与 Web 对齐的交互要点

  1. 创建：类型切换显隐素材；校验图 / 视频 / 图视包
  2. 编辑：不可改上架状态；个数不可低于已售
  3. 橱窗管理：置顶 / 下架 / 上架 / 移除 / 强制下架无自助上架；预览访客
  4. 购买：确认订单（余额）→ 余额不足或支付密码 → 成功；详情「已拥有」禁用购买
