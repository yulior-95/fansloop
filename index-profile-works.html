用户体验与信息架构

产品定位：FansLoop 是 Web3 创作者平台；「我的主页」是创作者管理个人品牌与内容资产的中心。作品 Tab 是最高频的内容管理入口。

核心用户需求：

  • 快速识别每条作品（标题 + 发布时间），管理曝光顺序（置顶）。
  • 临时下线不合规或过时内容（下架），而非直接删除。
  • 在下架区复核、永久删除；已发布区保持整洁。

交互逻辑：

  • 作品 Tab 内二级筛选：已发布 / 下架 — 互斥展示，下架作品仅在下架网格。
  • 卡片：封面 + 标题 + 时间 + 数据看板 + 置顶/下架（已发布）或 数据看板/删除（下架）。
  • 数据看板：页内弹窗 — 封面/标题/精确发布时间、六项总览、14 日播放峰值柱状图、粉丝三指标（各带研发玻璃球）。
  • 置顶最多 3 条；下架 → 确认 → 从已发布移动至下架 Tab。
