相对 8/3「充提手续费同表」方案，本期按产品要求去掉提现相关列与表单，避免与「充提限额 / 提现风控」能力重复表达。

3. 数字商品审核驳回闭环 新

3.1 运营后台

  • 点击「驳回」→ 确认弹窗，驳回原因必填（空原因不可提交）
  • 调用 DigitalAssetsStore.reject(id, reason)，状态 rejected，写入 rejectReason
  • 通过后状态 listed，进入 Creator Store

3.2 创作者橱窗（管理态）

  • 列表展示待审核 / 已驳回商品（排除草稿、已移除）
  • 驳回卡：红色横幅展示原因；操作「修改 / 重新提交」
  • 审核中卡：待审提示条
  • 种子数据含 da_seed_rejected_05（演示驳回态）

4. 橱窗 NFT 创建全流程 新

橱窗「创建数字商品」→ create-digital-asset.html?type=nft&from=showcase，固定 NFT 类型四步向导：

  1. 基础信息（名称、描述）
  2. NFT 素材（封面、媒体 URL、Traits）
  3. 发行设置（价格、链网络、限量/无限）
  4. 确认提交（预览 + 版权勾选 → pending_review）

提交后回到橱窗数字 Tab；可保存草稿。字段扩展：nftTraits、chainNetwork。

5. 佣金两层比例与玻璃批注 改

产品确认：商品同步的佣金比例与商城分成页「创作者分成」不是重复配置，而是两层分账。

位置字段业务含义
商品同步 · 佣金比例 commissionRate SKU 联盟佣金率：成交额 × 比例 = 联盟佣金（第三方 → 平台）
商城分成 · 创作者分成 affiliateCreatorSharePercent 二次分账：联盟佣金 × 比例 = 创作者实得；剩余为平台留存
  • 两处增加「To 研发」玻璃体批注：悬停显示、移出隐藏
  • 编辑同步商品弹窗的佣金字段旁同步批注
  • 样式 / 脚本：css/mall-dev-glass.css、js/mall-dev-glass.js（防 overflow 裁切）

6. 联盟佣金流水账务 改

6.1 状态中文

码值展示说明
pending待结算第三方已回传，尚未完成分账入账
settled已结算分账完成；原单保留不动
reverse冲正独立负向流水，关联原结算单

6.2 冲正 = 两条记录（非改状态）

  • 原「已结算」流水保留
  • 另开「冲正」记录：金额为负，relatedId 指向原单，可附退货备注
  • 创作者实得汇总 = 已结算 + 冲正（负向冲抵）

6.3 双订单号

字段含义
platformOrderNoGOODFANS 平台流水号（如 AC202608060105）；冲正另开新号
partnerOrderNo三方回传订单号（幂等键）；冲正可复用原三方单号

列表字体统一为 14px；清理无订单号的重复旧演示行。

10. 验收路径

  1. 后台「手续费」：确认无提现手续费 / 提现二维码列
  2. 橱窗管理态 → 创建数字商品 → 走完 NFT 四步 → 提交审核
  3. 后台「数字商品审核」→ 驳回并填原因 → 橱窗见红条原因并可重提
  4. 「商城分成配置 / 商品同步」悬停「To 研发」查看两层比例说明
  5. 「联盟佣金流水」：中文状态、双订单号、陶瓷杯结算+冲正两条
  6. 「数字销售记录」：可见多笔演示成交
  7. 打开 admin-prototype/mall-hifi/index.html 平铺评审五页
