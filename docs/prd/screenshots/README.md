# PRD 截图资源目录

将浏览器中打开的 **`pages-web/*.html`** 原型页面导出为 PNG，放入本目录，并与 [`../PRD-GOODFANS-Web-Prototype.md`](../PRD-GOODFANS-Web-Prototype.md) 中的引用文件名对齐。

## 建议命名

| 文件名 | 对应页面 | 截取区域建议 |
|--------|-----------|--------------|
| `home-aside-review-live.png` | `pages-web/home.html` | 右侧栏「待审核与预约」整块卡片 |
| `home-feed-composer.png` | `pages-web/home.html` | 信息流顶部 Composer + 预约直播条（若有） |
| `create-publish-live.png` | `pages-web/create-publish-live.html` | 弹窗整页 |
| `create-center-live.png` | `pages-web/create.html` | 「我的预约直播」区块 |

## 导出方式（示例）

- Chrome：打开本地 HTML → `Ctrl+Shift+P` → Capture screenshot（或使用开发者工具设备外的区域截图扩展）。
- 保证宽度 ≥ 1280px 以呈现桌面侧栏布局。
