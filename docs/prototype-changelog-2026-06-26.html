3. 运营后台 · 敏感词风控管理（新增）

页面： risk-sensitive-risk.html（新页面）
新增： js/risk-sensitive-risk-page.js · css/risk-sensitive-risk.css · js-web/sensitive-risk-store.js

Tab 1 · 异常敏感词数据

列表（12 列 + 分页）

序号、同场景次数、用户 UID、触发场景、触发时间、触发事件、操作 IP、状态、禁言倒计时、操作人、最新操作时间、操作

  • 仅展示 待处理 / 禁言中
  • 同场景次数：UID 在当前场景历史累计（IM / 直播分开）
  • sticky 列：序号、同场景次数、UID（左）+ 操作（右）
  • 操作：待处理 → 禁言/忽略；禁言中 → 解禁
  • 倒计时仅自动禁言小时；永久/人工为 --

筛选：用户 UID、状态、触发时间区间、最新操作时间区间；查询 + 重置

Tab 2 · 操作日志

列表（10 列 + 分页）

序号、异常次数（tooltip：截至本次风控历史触发次数含当前）、用户 UID、触发场景、触发时间、触发事件、操作 IP、操作事件、操作人、最新操作时间

  • sticky 列：序号、异常次数、UID（左）+ 最新操作时间（右）

筛选：用户 UID、操作时间、触发时间、最新操作时间（均为起止区间）；查询 + 重置

Tab 3 · 风控参数管理

全局统计策略

配置项选项
统计窗口近 7 / 30 / 90 天、终身累计
计数范围仅有效命中 / 全部命中（含已忽略）
启用场景即时聊天、直播互动（分场景独立计数）

阶梯规则

窗口内触发 ≥ N 次 → 结局（自动忽略 / 禁言小时 / 禁言永久 / 手动禁言）+ 禁言时长 + 启用

策略变更原则（保存弹窗）

  • 禁言中：维持现状，不追溯改判
  • 待处理：维持状态，不自动处置
  • 后续新命中：按新策略计数匹配
  • 可选同步待处理「触发事件」文案（不改变状态）
  • configVersion + 命中快照：已产生记录不追溯

触发事件示例： 7天内·直播互动≥8次 · 禁言小时（1h）
