1. C 端 · 钱包 · USDT / USDC 分账户管理

页面： pages-web/wallet.html

产品心智从「单一 USDT 钱包 + 隐藏多币资产」调整为稳定币双账户：总余额 = USDT + USDC，充提按账户余额扣减。

主要调整

  • 页头文案改为「USDT / USDC 分账户管理 · 多链充提」
  • 总余额展示为 $7,096.90，副文案拆分：USDT 5,816.40 + USDC 1,280.50
  • 「币种账户」区块取消 hidden：仅保留 USDT / USDC 两行，点击跳转充值页
  • 移除 ETH 等非稳定币资产行；账户标签统一为「多链」
  • 快捷操作区改为 4 列可见按钮（充值 / 提现 / 充提记录 / 账变）；「划转」按钮预留但 hidden（页面已就绪，入口暂不开放）

2. C 端 · 稳定币充值 · 币种可选

页面： pages-web/recharge.html
逻辑 / 样式： js-web/recharge-flow.js · css-web/recharge-flow.css

标题由「充值 USDT 账户」改为「稳定币充值」。币种下拉从静态固定 USDT，恢复为可交互选择。

交互要点

  • 充值币种下拉开放：仅支持 USDT / USDC（移除 BTC / ETH 选项）
  • 支持搜索稳定币；切换币种后联动网络列表与收款地址
  • USDT 网络：TRC20 / ERC20 / Polygon / Solana / BSC (BEP20)
  • USDC 网络：ERC20 / Polygon / Solana / BEP20
  • 去掉 .fl-dd-static-coin 静态禁用样式；补充 DAI / FDUSD 图标色（样式预留）

3. C 端 · 钱包提现 · 币种 + 按币网络

页面： pages-web/withdraw-usdt.html · pages-web/withdraw-fiat.html（链上提现区块）
逻辑： js-web/withdraw-usdt-flow.js

链上提现从「仅 USDT」扩展为「先选币种账户，再选该币支持的网络」，余额与手续费单位随币种切换。

交互要点

  • 新增「提现币种」下拉 wdDdCoin：USDT / USDC，从对应账户余额扣减
  • 网络列表改为 NETS_BY_COIN：USDT 含 TRC20 / ERC20 / BEP20 / Polygon；USDC 含 ERC20 / Polygon / Solana / BEP20
  • 可提现余额 Hero 字段由 data-max-usdt 改为 data-max-bal，金额单位、全部 链接、摘要行随币种同步
  • 提现入口文案统一为「USDT / USDC 转至链上地址」

4. C 端 · 账户划转（新增）

页面： pages-web/transfer.html
逻辑： js-web/transfer-flow.js（复用 css-web/recharge-flow.css 下拉组件）

平台内账本划转：USDT ↔ USDC，1:1、即时到账、无链上 Gas。钱包顶栏「划转」入口当前隐藏，可直接打开页面验收。

布局与功能

  • 左栏：转出 / 转入账户下拉 + 中间交换方向按钮 + 划转数量（支持「全部」）
  • 右栏：划转摘要（转出 / 转入 / 数量 / 预计到账）+ 说明卡
  • 互斥：转出与转入不可相同；金额不得超过可用余额
  • 提交成功：遮罩成功卡（继续划转 / 返回钱包），并本地扣减 / 增加演示余额

5. 运营后台 · USDT 充提限额 · 风控策略扩展

页面： admin-prototype/risk-usdt-limits.html
样式： admin-prototype/css/risk-usdt-limits.css（新增）

在原有「充提限额 + 大额提现冷静期」之上，补齐地址冷却与异常登录提现限制；保存动作均走谷歌验证码确认。

新增配置卡片

模块配置项说明
修改提现地址冷却期 启用开关 · 冷却时长（小时，默认 24） 用户新增/修改提现地址后，冷却期内禁止向该地址提现；平台级，用户端不可开关
异常 IP / 异常设备登录后提现限制 启用开关 · 限制时长（小时，默认 24） 命中异常登录后进入限制窗，禁止发起提现；旁侧「To 研发」玻璃批注写明判定逻辑与存储建议

To 研发 · 异常判定摘要

  • 异常 IP：非近 30 天常用 IP / geo 突变 / 代理·IDC·黑名单
  • 异常设备：非信任设备 / 新设备 / 模拟器·篡改等环境标记
  • 生效：登录成功后写入限制窗；提现下单前校验 withdraw_lock_until
