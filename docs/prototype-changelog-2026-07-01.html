  • 顶栏自动注入：铃铛 #adminBell、退出 #adminLogout

3. 全局轻提示（Toast → Message）

文件： js/admin-modal.js · css/admin-modals.css

筛选「重置」等操作原先弹出带「确定」按钮的 Modal（#admin-fl-modal-root），打断操作流。
  • AdminModal.toast() 改为顶部全局 notify()，约 2.8s 自动消失（对齐 Ant Design Message）
  • 新增类型色：success / warning / error / info；按文案自动推断类型
  • 新增别名 AdminModal.message
  • Google 验证失败/通过亦改为轻提示，不再弹确认框
  • AdminFilterToolbar 默认「筛选已应用 / 已重置」同样走轻提示

5. AdminFormControls · Select 下拉修复
