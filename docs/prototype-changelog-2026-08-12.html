1. 产品定义

数字产品 = 创作者上传并售卖的 图片合集 或 视频作品（非链上 NFT）。审核通过后上架 Creator Store / 橱窗；购买后即时获得浏览合集 / 播放视频权益。

本期明确不做：NFT Traits / 链网络 / 铸造空投交互；会员权益与独家内容作为可创建类型；真实文件上传（仍用 URL 列表模拟）。

2. 数据模型

  • ASSET_TYPES 仅保留 image（图片合集）、video（视频作品）
  • localStorage 升级为 fl_digital_assets_v7；旧类型迁移归并为 image/video，并清理展示用 NFT 字段
  • create() 新写入不再带 nftTraits / chainNetwork
  • 订单种子 fl_digital_asset_orders_v3：商品标题与类型改为图片 / 视频
  • 驳回样例原因改为版权 / 素材质量相关

3. 创建向导（四步）

  1. 类型与基础信息：单选图片合集 / 视频作品 + 标题 + 描述
  2. 作品素材：封面 URL；合集 = 多图 URL 列表；视频 = 视频 URL
  3. 售卖设置：价格 USDT、限量 / 无限（无链网络、Traits）
  4. 确认提交：预览 → 版权勾选 → pending_review

橱窗入口：create-digital-asset.html?from=showcase（不再强制 type=nft）。

4. C 端表面

  • Creator Store / 橱窗：类型标签「图片合集」「视频作品」；创建文案去 NFT
  • 购买弹窗：交付说明改为「购买后可浏览合集 / 播放视频」
  • 「我的作品」页：已购合集与视频库

5. 后台与高保真

页面调整
数字商品审核类型仅图片合集 / 视频；驳回文案偏版权与素材质量
数字商品管理状态筛选保留；类型展示新标签
数字销售记录随订单种子更新商品名 / 类型
mall-hifi 三页演示数据与筛选与上表对齐；index UX 去掉 NFT 表述

规格文档 commerce-dual-mall-spec.html 中 assetType 枚举已改为 image / video。

6. 验收路径

  1. 橱窗 → 创建数字商品：可选图片合集（多图）或视频，无 Traits / 链
  2. 提交后进审核队列；驳回原因在橱窗可见并可重提
  3. 通过后 Creator Store / 橱窗可售；购买后「我的作品」可见
  4. 后台审核 / 管理 / 销售记录类型仅为图片合集或视频
  5. 数字商品主路径文案无「NFT / 链上」表述
