1. 运营后台 · 报表统计（增强）

4. C 端 · 侧栏导航防闪烁 + 收入 Chip

逻辑： js-web/app-sidebar-global.js · js-web/creator-income-store.js · css-web/common-web.css

相对 7/1：切换菜单（如积分商城 ↔ 账变记录）时侧栏不再出现「静态菜单 → 重建 → 底部刷新」的连续闪动。

防闪烁策略

  • 首屏 CSS：未设置 data-fl-nav-unified 前隐藏静态菜单区，仅保留品牌区
  • sessionStorage 缓存侧栏 HTML（fl_sidebar_shell_v1），跨页优先恢复，仅更新 active 高亮
  • 同步渲染侧栏，不再等待 creator-income-store.js 异步加载后才首次绘制
  • 认证脚本就绪后仅增量更新底部用户区，避免重复 innerHTML 重建

创作者收入 Chip

  • 侧栏「创作者收入」右侧标签统一为 +298.4 USDT 格式
  • 切换页面时仅更新 chip 数值，不整棵重建导航
  • 各页静态占位 +$28 已移除

5. C 端 · 侧栏收起菜单名气泡（新增）

逻辑： js-web/app-sidebar-global.js · css-web/common-web.css

7. C 端 · Creator Pro「立即升级」完整交互

逻辑： js-web/sidebar-bottom-interactions.js · js-web/creator-pro-store.js · css-web/sidebar-bottom.css

相对 7/1：侧栏「立即升级」由单步模拟开通，补齐完整结算原型流程。

流程（6 步）

步骤说明
1 方案选择月付 $19 / 年付 $190
2 确认订单订单摘要 + 钱包 USDT 余额 + 6 位支付密码键盘
3 余额不足引导充值 wallet.html，支持 fl_pro_upgrade=open 回跳
4 未设支付密码跳转 settings-pay-password.html
5 支付处理中验证密码 + 扣款动画（约 1.1s）
6 开通成功展示方案与到期日；侧栏 Pro 卡片隐藏，用户行显示「会员」标签
  • 已是会员时再次点击提示「你已是 Creator Pro 会员」
  • 个人主页「前往结算」接入同一弹层（FL_openProUpgradeOverlay）
  • 会员状态写入 localStorage · fl_creator_pro_v1

8. C 端 · 评论弹窗内联化（本页弹出）

页面： pages-web/comment-modal.html
逻辑： js-web/fl-interaction-modal.js · js-web/comment-modal-inline.js · css-web/comment-modal.css

相对 7/1：Feed 点击评论不再使用 iframe 嵌套独立页，改为与打赏弹窗一致的内联 DOM 注入，便于 Cursor 选中内部元素微调。

改动要点

  • openCommentInline()：fetch 评论页 HTML，提取 .cm-modal 注入 #flStandaloneModalRoot
  • 仅保留蒙层 + 评论面板，去掉 iframe 外围紫蓝渐变与底部多余区域
  • 移除评论独立页的语言切换组件（global-lang-switch）
  • 输入区背景与弹窗同色，去掉底部深色衬底
  • 支持 ?benefitScene=comment-highlight 权益高亮联动

9. C 端 · Feed 帖子正文超长折叠（新增）

逻辑： js-web/feed-stack-builder.js · js-web/feed-post-text-clamp.js · css-web/home-feed-v2.css

  • 沉浸态 Feed 卡片正文默认最多 3 行，超出显示省略

  • 部分条目（索引 % 8 === 0）加长文案便于验收折叠效果
  • Feed 重建版本号升至 data-version="12"
