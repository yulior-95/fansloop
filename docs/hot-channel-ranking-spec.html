1. 设计原则与原方案总体问题

1.1 五条设计原则

原则说明
量纲可比任何进入加权求和的因子必须先归一化到 [0,1]，绝不允许「计数 + 比率」直接相加。
硬门槛与打分分离审核状态、举报、合规这类是准入门槛，只决定「能不能进池」，不参与加权打分。
小样本不失真所有比率必须做贝叶斯平滑或取 Wilson 置信下界，杜绝「3 次播放 3 个赞 = 100% 互动率」霸榜。
信号不重复计算同一用户行为只在一个因子里出现一次，避免变相加权。
贴合创作者经济打赏、订阅转化、付费解锁是本平台最高价值信号，权重必须显著高于点赞。

1.2 原方案的五个共性问题

问题 A｜量纲混加，权重失效 「播放量增长速度 × 30%」与「完播率 × 20%」相加时，前者量级可能是 5000，后者是 0.6， 最终分数 99.99% 由播放速度决定，其余权重形同虚设。爆款视频的公式问题更严重—— 累计播放量 + 各种率 实际等价于「按播放量排序」。
问题 B｜信号重复计算 原方案定义「互动率 =（点赞+评论+收藏+分享）/ 播放人数」， 但今日热门又把收藏率、分享率各自单列 10%。收藏和分享被算了两遍，实际权重被放大。
问题 C｜小样本可以刷榜 所有比率型指标都没有最小曝光门槛和平滑处理。一条只有 10 次播放、8 次点赞的内容， 互动率 80% 会直接压过一条 10 万播放、互动率 12% 的优质内容。
问题 D｜只有正向信号，没有负向约束 五个槽位里只有「最新发布」提到举报。缺少「不感兴趣」「秒退（3 秒内划走）」「拉黑」 等负反馈，也缺少刷量识别，算法可以被低成本操纵。
问题 E｜缺少时间窗口定义 「今日热门」没说是自然日还是滚动 24 小时；「爆款视频」用累计播放量且无时间窗， 会导致一条半年前的老爆款永久占据槽位，频道失去更新感。

2. 通用计算框架

2.1 统一打分结构

五个槽位全部套用同一个三段式结构，差异只体现在门槛条件与加权项：

// 三段式：门槛 → 加权 → 修正 最终分 = Σ( 权重ᵢ × norm(因子ᵢ) ) // 加权项，结果 ∈ [0,1] × decay(Δt) // 时间衰减 × penalty // 负反馈惩罚 × trust // 反作弊信任分 × access // 付费可见性系数 // 任一硬门槛不通过 → 直接不进候选池，不计算分数

2.2 归一化 norm()：解决量纲问题

采用同期同池百分位归一化，而不是 min-max：百分位对刷量产生的极端值天然鲁棒， 且不需要预设量级上限。对播放量这类长尾分布的计数指标，先做对数压缩再取百分位。

norm(x) = percentile_rank(x, pool) ∈ [0, 1] // 计数型（播放、点赞数…）先压缩长尾 norm(V) = percentile_rank( log(1 + V), pool ) // pool = 同一时间窗 + 同一一级类目 的候选集合 // 同类目对比可避免「美食天然比知识播放高」造成的系统性偏差

2.3 小样本平滑：杜绝低播放霸榜

所有比率型指标使用贝叶斯平滑，用类目历史均值作为先验，把样本不足的内容拉回均值：

rate_smooth = ( x + α × μ_cat ) / ( n + α ) x = 行为发生次数（如完播次数） n = 分母基数（如播放人数） μ_cat = 该三级类目近 30 天该指标的均值（先验） α = 先验强度，建议 α = 200 // 效果：n=10 时几乎等于类目均值；n=5000 时几乎等于真实值

对需要保守估计的场景（如高互动槽位），改用 Wilson 95% 置信下界，宁可低估也不误推。

2.4 时间衰减 decay()

decay(Δt) = 0.5 ^ ( Δt / H ) // H = 半衰期
槽位半衰期 H理由
今日热门6 小时强调「此刻正在热」，半天前的热度应明显退坡
爆款视频72 小时爆款需要沉淀期，衰减要慢，但仍需让位给新爆款
高互动内容24 小时互动质量相对稳定，中速衰减
新创作者不衰减由 30 天扶持期与毕业机制控制生命周期
最新发布2 小时时效性最强，2 小时后排序权重减半

2.5 负反馈惩罚 penalty

负反馈率 NFR = ( 1.0×不感兴趣 + 1.5×秒退 + 5.0×举报 + 8.0×拉黑创作者 ) / 曝光数 penalty = 1 − min( 0.6, 25 × NFR ) // 惩罚上限 60%，不做一票否决 // 秒退 = 视频进入后 3 秒内退出 / 图文进入后 2 秒内退出 // 举报率 ≥ 0.5% 或举报绝对数 ≥ 3 → 转硬门槛，直接下架并送人工复审

2.6 付费内容可见性系数 access

与现有 js-web/discover-access.js 保持一致，避免算法与前端展示规则打架：

场景access说明
免费内容1.0完整可消费
付费内容 · 当前用户已订阅/已解锁1.0等同免费
付费内容 · 当前用户未订阅0.55只能看 Teaser，消费体验打折
游客—付费内容不进候选，只出 5 条免费内容
注意：付费内容的率值要按可见部分归一 未订阅用户看到的是 12 秒 Teaser，其「完播率」不可与免费长视频直接比较。 付费内容的完播率应按 已订阅用户的观看数据 单独统计，避免系统性低估付费优质内容。

3. 互动行为权重表

原方案把点赞、评论、收藏、分享等权相加，这在创作者经济平台上是明显失真的—— 点赞几乎零成本，而订阅意味着真金白银。权重按用户付出成本 × 商业价值递增设定：

行为权重 w说明
点赞1成本最低，最易刷，作为基准单位
收藏3延时消费意图，质量信号强于点赞
弹幕3直播/视频场景的实时参与
评论5需要组织语言，成本高；需过滤灌水（见 9.3）
分享8愿意用社交关系背书，站外分享额外 ×1.5
关注创作者12长期关系建立，对创作者增长最关键
打赏 / 送礼15付费行为，按次计（金额单独进变现指标，不进热度分）
付费解锁（PPV）25为单条内容直接付费，最强的内容质量信号
订阅创作者40最高价值转化
加权互动分 A = Σ ( wᵢ × 行为次数ᵢ ) // 防刷：单个用户对单条内容的贡献上限 60 分 // 金额不进热度分，避免大额打赏单点拉爆排序；金额只用于创作者收益榜
1 今日热门 hot-today

4.1 原方案与问题

原方案问题修正
播放量增长速度 × 30% 无上界的计数值，直接吞掉其余 70% 权重 取 log(1+增速) 后做同类目百分位归一
互动率 × 30% 按原定义含收藏与分享，与后两项重复计算 互动率剔除收藏与分享，只保留点赞/评论/弹幕/打赏
完播率 × 20% 低播放量内容完播率虚高 贝叶斯平滑 + 最小播放门槛
收藏率 10% / 分享率 10% 权重本身合理，但被重复计入互动率 保留权重，去重后独立计算
（缺失） 没有时间窗、没有衰减、没有负反馈、图文与视频混排不公平 补齐窗口定义、衰减、惩罚，并按内容形态分池

4.2 修正后算法

硬门槛 全部满足才进候选池

  • 内容审核状态 = 通过，且未被举报下架
  • 发布时间在最近 7 天内（保证「今日热」的内容本身不老）
  • 滚动 24 小时内曝光 ≥ 1000，独立播放人数 ≥ 200
  • 举报率 < 0.5%，信任分 trust ≥ 0.6

加权打分

S_today = 0.30 × norm( log(1 + 播放增速 Vph) ) // 增长速度 + 0.30 × norm( 加权互动率 IR_w ) // 不含收藏分享 + 0.20 × norm( 完播率 CR_smooth ) + 0.10 × norm( 收藏率 FR_smooth ) + 0.10 × norm( 分享率 SR_smooth ) 最终 = S_today × decay(H=6h) × penalty × trust × access 其中： Vph = 最近 6 小时播放量 / min(6, 已发布小时数) // 避免刚发布时分母过小 IR_w = (1×点赞 + 5×评论 + 3×弹幕 + 15×打赏) / 独立播放人数 CR_smooth = (完播次数 + 200 × μ完播_类目) / (播放次数 + 200) FR_smooth、SR_smooth 同理

边界与兜底

  • 分池：视频与图文分开计算百分位（图文没有完播率，其 20% 权重按比例分摊给互动率与收藏率）
  • 时间窗：滚动 24 小时，不是自然日；每 15 分钟重算一次
  • 直播：进行中的直播单独用「实时在线人数增速 + 礼物流水增速」评估，不与录播混排
  • 候选不足：放宽曝光门槛到 500，仍不足则从「爆款视频」池回填
2 爆款视频 hot-viral

5.1 原方案与问题

原公式实际等价于「按播放量排序」 累计播放量 + 点赞率 + 评论率 + 收藏率 + 分享率 + 完播率： 播放量量级为 10⁴~10⁶，五个率之和最大不超过 5。也就是说后面五项加起来的影响， 还不如播放量多 5 次播放。而且六项无权重、无时间窗，老爆款会永久占位。
修正思路：把播放量从「打分项」改成「门槛项 + 弱权重项」 「爆款」的本质不是播放量绝对值高，而是突破了创作者自己的粉丝圈层并产生了自发传播。 因此新增两个原方案完全缺失的核心因子：传播系数 K 与 破圈率。

5.2 修正后算法

硬门槛

  • 发布时间在最近 30 天内，且已发布满 24 小时（需要沉淀期才能判断是否爆）
  • 累计播放量 ≥ max(50,000, 同类目近 30 天 P90)——用相对门槛避免冷门类目永远出不了爆款
  • 审核通过、信任分 trust ≥ 0.8（爆款位曝光大，反作弊要求更严）
  • 完播率 ≥ 同类目 P30（排除靠标题党骗进来的高播放低质内容）

加权打分

S_viral = 0.25 × norm( log(1 + 累计播放 V) ) // 规模，压缩后弱权重 + 0.20 × norm( 传播系数 K ) // 自发扩散能力（新增） + 0.15 × norm( 破圈率 OutR ) // 是否突破粉丝圈（新增） + 0.15 × norm( 完播率 CR_smooth ) + 0.10 × norm( 分享率 SR_smooth ) + 0.10 × norm( 评论率 CmR_smooth ) + 0.05 × norm( 收藏率 FR_smooth ) 最终 = S_viral × decay(H=72h) × penalty × trust × access 其中： K = 由分享链接带来的新增播放数 / 分享次数 // 病毒系数，K>1 表示自增长 OutR = 非粉丝播放人数 / 总播放人数 // 破圈率

点赞率不单列——它是最易刷且区分度最低的信号，已在信任分与互动质量校验中使用。

边界与兜底

  • 防霸榜：同一条内容在爆款位累计出现不超过 7 天，到期强制轮换
  • 同创作者上限：爆款位内同一创作者最多 1 条
  • 名副其实校验：进入爆款位后若 CTR 低于槽位均值 50%，2 小时内自动降位
3 高互动内容 hot-engaged

6.1 原方案与问题

原方案问题修正
点赞、评论、收藏、分享等权相加 点赞成本趋近于 0，评论/分享成本高数十倍，等权会让「点赞刷子」直接登顶 启用第 3 节的差异化权重表
缺少平台高价值行为 打赏、订阅转化、付费解锁——本平台最核心的信号完全没纳入 纳入并给予最高权重（15 / 40 / 25）
分母「播放人数」未定义 是否去重直接影响结果，重复播放会稀释互动率 明确为独立播放人数 UV，同一用户当日多次播放算 1
无最小样本、无平滑 5 播放 5 互动 = 100%，必然霸榜 UV ≥ 300 门槛 + Wilson 置信下界
无负向项 争议性内容（大量对骂评论）会被判为「高互动」 引入负反馈惩罚 + 评论健康度系数

6.2 修正后算法

硬门槛

  • 独立播放人数 UV ≥ 300
  • 评论健康度 ≥ 0.7（非灌水、非辱骂评论占比，由敏感词与相似度模型判定）
  • 审核通过、trust ≥ 0.7

加权打分

加权互动分 A = 1×点赞 + 3×收藏 + 3×弹幕 + 5×评论 + 8×分享 + 12×关注 + 15×打赏 + 25×付费解锁 + 40×订阅 （单用户单条内容贡献上限 60） 互动率 IR = A / UV 平滑 IR_smooth = ( A + 100 × μ_A_类目 ) / ( UV + 100 ) S_engaged = norm( IR_smooth ) × 评论健康度 × decay(H=24h) × penalty × trust × access

边界与兜底

  • 互动来源集中度校验：Top 10 用户贡献 > 40% 加权互动分 → 该内容 trust ×0.5
  • 争议内容识别：负面情感评论占比 > 60% 时不进该槽位，即使互动率极高
  • 形态公平：直播回放、图文、视频分池排名后按 4:3:3 混合，避免单一形态垄断
4 新创作者 fresh-creator

7.1 原方案的致命问题

OR 条件会让头部创作者混进新人扶持位 原条件「注册 < 30 天 或 粉丝 < 1000 或 发布作品 < 10」中， 任意一条满足即可。一个注册 3 年、拥有 50 万粉丝、但只发过 8 条作品的头部创作者， 因「发布作品 < 10」成立而占据新人位——这会让扶持资源完全失效。
必须改成 AND。
缺少合规门槛，等于给养号刷粉开后门 新号 + 低粉是刷量团伙的典型特征。没有实名、原创校验、违规记录检查， 这个槽位会迅速被搬运号和引流号占领。
只定义了「谁能进」，没定义「怎么排」和「什么时候出去」 新创作者天然没有播放量，如果沿用热度排序，永远排不上来； 同时缺少毕业机制，会导致同一批人长期霸占扶持位。

7.2 修正后算法：资格 → 合规 → 潜力排序 → 保量 → 毕业

第一步：资格判定（AND，全部满足）

条件阈值说明
首次发布内容时间≤ 30 天用「首次发布」而非「注册」，避免注册后长期不活跃再突然发力
粉丝数< 1000与毕业条件对齐
累计发布作品< 10—
未毕业—见 7.4 毕业机制

第二步：合规门槛（新增，全部满足）

  • KYC / 实名认证已通过
  • 近 90 天无内容违规记录，账号未处于限流或封禁状态
  • 本条内容审核通过，且原创校验通过（非搬运、非重复投稿）
  • 创作者资料完整：头像、昵称、简介、主营类目均已填写

第三步：潜力排序（不用热度，用转化质量）

// 新人没有播放量基数，只能看「小样本下的转化效率」 S_new = 0.35 × norm( 完播率 CR_smooth ) + 0.30 × norm( 加权互动率 IR_w ) + 0.20 × norm( 关注转化率 FollowR ) // 看完后关注的比例，最能代表创作者潜力 + 0.15 × norm( 内容完整度 Quality ) // 封面/标题/类目/标签/简介齐全度 最终 = S_new × penalty × trust // pool 限定为「同期新创作者候选集」，只和同批新人比，不和成熟创作者比 FollowR = 观看后关注创作者人数 / 独立播放人数

第四步：保量扶持（原方案缺失）

光有排序不叫扶持，必须给保底曝光，否则新人永远拿不到第一批数据：

阶段曝光配额晋级条件
冷启动池3,000 次曝光互动率 ≥ 同类目 P50 且负反馈率 < 2%
加速池追加 10,000 次互动率 ≥ 同类目 P70
常规池不限，转入通用推荐—

未达晋级条件的内容退出扶持，不再追加曝光；创作者仍可用剩余作品重新进入冷启动池。

第五步：毕业机制（原方案缺失）

满足任一条件即毕业，退出新创作者池，把位置让给下一批新人：

  • 粉丝数 ≥ 1000
  • 任一作品播放量 ≥ 50,000
  • 首次发布满 30 天
  • 累计发布 ≥ 10 条
槽位质量下限 新创作者内容在热门频道整体信息流中的占比上限为 20%。 扶持不能以牺牲整体消费体验为代价，否则会伤害用户对「热门」的信任。
5 最新发布 fresh-latest

8.1 原方案与问题

把硬门槛当成了打分项 原方案「发布时间 + 账号质量分 + 审核状态 + 用户举报」把四项并列相加。 但审核状态是布尔量——未通过的内容根本不该出现在任何位置， 而不是「扣一点分但仍可展示」。用户举报同理，达到阈值应立即撤下。 这两项必须从加权公式中移出，改为准入门槛。
质量分权重过高会让「最新」名不副实 如果账号质量分权重与时间相当，排在最前面的可能是 20 小时前的大 V 内容， 而不是 5 分钟前的新内容，槽位就失去了存在意义。时间必须占绝对主导。

8.2 修正后算法

硬门槛（原「审核状态」「用户举报」移到这里）

  • 内容审核状态 = 通过（审核中、驳回一律不进池）
  • 举报数 < 3 且举报率 < 0.5%；触线即刻从槽位撤下并转人工复审
  • 账号状态正常（非封禁、非限流、非风控观察期）
  • 非重复投稿（与该创作者近 7 天内容的相似度 < 0.9）
  • 发布时间在 24 小时内（候选不足时放宽至 72 小时）

加权打分（时间主导）

S_latest = 0.70 × 时间新鲜度 f(t) + 0.30 × 账号质量分 Q f(t) = 0.5 ^ ( Δt / 2h ) // 2 小时半衰期 账号质量分 Q ∈ [0,1] = 0.40 × 历史内容质量分 // 近 30 天作品的平均完播率与互动率分位 + 0.30 × 合规记录分 // 违规次数、举报率的反向映射 + 0.20 × 粉丝互动健康度 // 真实粉丝占比、互动来源分散度 + 0.10 × 资料完整度 最终 = S_latest × penalty × access

边界与兜底

  • 刷屏保护：同一创作者 30 分钟内最多 1 条进池
  • 新人保底：该槽位为新创作者预留 30% 名额，避免被高质量分的成熟账号挤满
  • 刷新频率：每 1 分钟重算，接近实时
  • 先发后审场景：若平台开启先发后审，未过审内容仅创作者自己可见，绝不进入该槽位

9. 反作弊与信任分

9.1 信任分 trust

trust ∈ [0,1]，作为全局乘子作用于所有槽位。初始值 1.0，命中以下规则逐项相乘扣减：

检测项触发条件系数说明
播放增速异常> 同类目历史 P99.9×0.3进入观察队列，2 小时内不进热门
互动来源集中Top 10 用户占比 > 40%×0.5典型的互赞群 / 水军特征
新号互动占比高注册 < 7 天用户占比 > 60%×0.4批量小号刷量
设备/IP 聚集同 IP 段互动 > 30%×0.3机房刷量
互动时间分布异常行为间隔方差极低×0.5脚本机器人特征
完播率异常> 95% 且播放 > 1 万×0.6真实长视频极难达到，疑似挂机
创作者历史违规近 90 天有处罚×0.7累犯叠加

9.2 计数去重规则

  • 播放：同一用户对同一内容，24 小时内多次播放只计 1 次 UV；视频需播放 ≥ 3 秒才计有效播放
  • 点赞/收藏：取消后重新操作不重复计数
  • 分享：按「分享落地页产生的新访问」计有效分享，空点分享按钮不计
  • 被判定为作弊的行为数据从分子中剔除，而不只是降权

9.3 评论健康度

评论健康度 = 有效评论数 / 总评论数 ∈ [0,1] // 以下不计入有效评论： - 长度 < 2 字符或纯表情 - 与同内容下其他评论相似度 > 0.9（复制刷屏） - 命中敏感词库或辱骂模型 - 同一用户在同一内容下的第 4 条及以后的评论

10. 多样性、去重与兜底

规则约束
同创作者约束单个槽位内最多 1 条；热门频道整页最多 2 条
跨槽位去重同一条内容同时命中多个槽位时，只保留优先级最高的一个。
优先级：今日热门 > 爆款视频 > 高互动 > 新创作者 > 最新发布
类目多样性用 MMR 打散，同一一级类目连续出现不超过 3 条
已消费过滤用户已完整消费过的内容 7 天内不重复推荐；已曝光未点击 3 次后降权 50%
候选不足兜底依次回填：放宽门槛 → 扩大时间窗 → 从相邻槽位借用 → 全站热度榜。槽位不允许为空
合规兜底任何时刻内容被下架/封禁，须在 60 秒内从所有槽位缓存中清除

13.2 A/B 实验设计

  • 分流：按用户 ID 哈希分桶，每组不低于 5% 流量，实验周期 ≥ 14 天（覆盖两个完整周周期）
  • 建议首批实验：
    1. 归一化方式：百分位 vs z-score
    2. 今日热门半衰期：4h / 6h / 12h
    3. 互动权重表：等权（原方案）vs 差异化权重（新方案）
    4. 新创作者占比上限：10% / 20% / 30%
  • 停止条件：护栏指标恶化超过 5% 立即回滚

附录 · 与当前原型实现的差距

原型 js-web/discover-access.js 目前的热度计算为：

hotScore = 点赞数 + 评论数 × 2 + (置顶 ? 800 : 0) 未订阅付费内容 → × 0.55

这是一个仅用于前端演示的极简版本。它与本文的差距在于：无归一化、无平滑、无时间衰减、 无负反馈、无反作弊、无五槽位区分。付费降权 0.55 这一项已与本文一致，其余需在服务端实现。 原型阶段可先补充「时间衰减」与「五槽位分流」两项，使演示效果贴近真实排序。
