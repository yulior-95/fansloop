1. 整体定位与硬边界

GOODFANS 商城包含两条完全独立的业务线，在创作者侧统一汇入「创作者橱窗」：

  1. 数字虚拟资产商城（Creator Digital Assets） — 创作者自建资产，站内支付，即时发放权益。
  2. 实体商品商城（Affiliate Physical Products） — 第三方联盟商品库 + 创作者选品推广，外跳成交 + 佣金回传。
统一橱窗入口 每个创作者个人详情页展示「橱窗」入口。进入后同时看到：本人创建的数字商品 + 从商品中心选品的实体商品。 访客可购买；本人视图（?owner=1）无购买按钮，提供「从商品中心选品 / 创建数字商品」与数据面板。
明确不做 平台库存仓储、物流追踪、收货地址、发货流程、供应链、实体商品平台内支付订单。两条业务线禁止共用同一商品表或同一购买流程。
核心转化链路 内容产生流量 → AI 发现商品（实体）→ 创作者推广 → 用户购买 → 平台与创作者获得收益。

2. 数字虚拟资产商城

2.1 业务流程

  1. 创作者进入橱窗 → 创建数字商品（图片合集 / 视频作品）
  2. 上传内容与封面，设置价格 / 发行量 / 发布时间
  3. 提交平台审核 → 通过后上架 Creator Store
  4. 用户购买（USDT）→ 订单完成 → 立即获得数字权益
  5. 收益进入创作者收益账户（扣平台服务费）

2.2 数据模型 digital_product

字段类型说明
idstring商品 ID
creatorId / creatorNamestring创作者
title / description / coverUrlstring展示信息
assetTypeenumimage（图片合集）/ video（视频作品）；历史 nft/membership 等已迁移归并为 image
contentFiles[]string[]数字内容文件 URL
priceUsdtnumber创作者定价
supplyModeenumunlimited / limited
supplyTotal / soldCountint商品个数（可售份数）与已售份数；剩余 = total − sold，售罄自动转 sold_out
autoListbool创作者创建时选择的上架状态：true = 审核通过后立即上架；false = 通过后保持 delisted，由创作者手动上架
statusenumdraft / pending_review / rejected / listed / sold_out / delisted
publishedAt / rejectReasonstring发布时间 / 驳回原因

状态机：draft → pending_review → listed | delisted | rejected（autoList=false 时通过进入 delisted）；限量售罄自动 sold_out；创作者可随时在橱窗切换 listed / delisted。

2.3 订单与权益

  • digital_order：buyerId、productId、priceUsdt、platformFee、creatorNet、createdAt、status=completed
  • user_digital_entitlement：购买成功即时写入，用户「我的作品」可读
  • 无物流、无地址、无发货步骤
creatorNet = priceUsdt × (1 − digitalPlatformFeePercent / 100) platformFee = priceUsdt − creatorNet // 默认 digitalPlatformFeePercent = 10 → 创作者 90%

3. 实体联盟商品商城

3.1 业务流程

  1. 第三方商城 API 同步 → GOODFANS 商品库
  2. 创作者浏览商品库 → 加入个人橱窗
  3. 内容推广 / AI 识别展示商品卡
  4. 用户点击 → 跳转第三方完成支付、库存、发货、售后
  5. 第三方回传成交佣金 → GOODFANS 分配给创作者

3.2 数据模型

affiliate_partner：id、name、apiEndpoint、enabled、commissionNote

affiliate_product：

字段说明
id, partnerId, externalId同步主键
title, imageUrl, description, priceDisplay展示
categoryId, tags[], affiliateUrl分类 / 匹配 / 外跳
commissionRate第三方联盟比例（如 0.05）
embeddingHint向量占位，供 AI 匹配
syncStatus, syncedAt同步状态

showcase_item：creatorId + productId + pinned + addedAt

affiliate_click / affiliate_commission：点击与佣金回传流水

禁止字段 实体商品不得出现平台库存、物流单号、收货地址。成交与履约均在第三方。
affiliateGross = orderAmount × commissionRate // 第三方付给 GOODFANS creatorShare = affiliateGross × (affiliateCreatorSharePercent / 100) platformShare = affiliateGross − creatorShare // 默认 affiliateCreatorSharePercent = 70

5. AI 商品识别关联

  1. 用户观看视频 → 暂停
  2. 前端调用匹配（原型：按 tags / embeddingHint 相似度）
  3. 从实体商品库取 Top-N → 展示商品卡
  4. 点击 → 外跳 affiliateUrl 并记 click

依赖字段：imageUrl、title、categoryId、tags、embeddingHint。

6. 收益与结算

  • 数字商品（图片合集 / 视频）：T+0 即时入账演示；配置源 MallCommerceConfigStore.digitalPlatformFeePercent
  • 联盟佣金：回传后入账；配置源 affiliateCreatorSharePercent
  • 创作者收入页展示分项：数字商品销售 / 联盟佣金
  • 分成页（creator-income-split）对上述两项展示只读摘要，主配置在商城配置页，避免双写

8. 与积分商城的隔离

  • points-mall.html 保持积分兑换权益，不承载数字商品或联盟商品
  • 命名：Creator Store / 数字商品（图片合集·视频作品）/ 实体橱窗 / Affiliate，禁止复用「积分商城」文案

9. 验收清单

  1. 创建 → 审核 → 上架 → 购买 → 我的资产 → 创作者收益（扣平台费）
  2. 限量售罄自动 sold_out；无限发行不展示剩余
  3. 同步联盟商品 → 加入橱窗 → 外跳 → 佣金回传 → 创作者收益
  4. 视频暂停 AI 商品卡 → 外跳
  5. 无地址/物流/库存履约 UI；积分商城路径不受影响
