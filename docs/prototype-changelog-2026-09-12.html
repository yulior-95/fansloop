2. 浅色主题可读性 新改

需求

  • H5 以 html[data-theme="light"]、h5_settings_theme 为准；Web 以 html[data-fl-theme="light"] 为准。
  • 首屏须在 <head> 同步主题，避免浅色 FOUC。
  • 暗色可用的 pastel（#FBBF24 / #6EE7B7 / #FCA5A5 / #93C5FD）在浅色白底上不得直接当正文色。
  • 浅色功能色统一落到主题变量，避免各页各写一套：
    • 支出 / 危险：#DC2626 / #b91c1c
    • 收入 / 成功：#047857
    • 处理中 / 警告：#B45309 / #92400E
    • 信息：#1D4ED8
  • H5 弹层（评论、分享、私信、订阅）须留在手机壳内（position: absolute），浅色下为白底深字；信息流本身可继续黑底。
  • 全局 .cancel 不得被刷成灰底按钮块（订阅搜索「取消」除外）。

相对上次

  • 上次：H5 无独立浅色覆盖表；Web 只改了 --danger-light。
  • 本次：新增 css/h5-light-theme.css + js/h5-theme-boot.js；同套规则同步进 css/common.css 尾部；Web 在 global-display-prefs.css 补齐 warning / success / info。

3. 邮箱登录：验证码 + 密码 新

需求

  • Web（modal-login-main.html）与 H5（login.html）邮箱入口均提供 验证码登录 | 密码登录 切换。
  • 演示密码 123456；注册时写入 localStorage.fl_email_pwds。
  • new-user@example.com 仍走注册补全资料。
  • 忘记密码：Web 打开 modal-email-forgot-password.html，完成后回到 modal-login-main.html?tab=email#pwd；H5 用页内重置半层。

相对上次

上次邮箱仅验证码；本次补密码登录与重置回跳，两端文案与状态一致。

4. 首页分享与弹层 改

  • 分享半层改为 flex、最大高度约 82%、内容可滚，避免裁切。
  • 「分享到私信」为整行入口（非小图标）；可选互关好友、搜索、发送。
  • 遮罩与半层不得溢出 H5 375×812 机框。
  • 浅色下评论 / 分享 / 私信 / 订阅半层白底；信息流保持黑底。
  • ensureReadableTextInLightTheme 跳过 .home-overlay / .home-sheet / .live-modal-sheet / .creator-search-inline / .tag / .status，避免把语义色刷成正文色。

5. 订阅信息流交互 新改

查找创作者

  • 「取消」在搜索胶囊外侧，紫色文字、无灰底块。

分享

  • 上次：H5 分享图标会跟着卡片跳创作者主页；Web 抽屉分享只 toast。
  • 本次：H5 点分享打开与首页同结构的半层（私信 / 第三方 / 复制链接）；Web 预览底栏与详情抽屉分享走 share-modal.html。

点赞 / 评论 / 收藏

  • 点击三项不得跳转详情或主页（stopPropagation）。
  • 点赞：切换实心红心，toast「已点赞 / 已取消点赞」，数字加减。
  • 收藏：切换实心书签，toast「已收藏 / 已取消收藏」，数字加减。
  • 评论：打开半层（示例评论 + 输入发送）；空内容提示「请输入评论内容」；发送成功上墙且卡片数字 +1。
  • 卡片空白处仍进详情（data-detail-go）。
  • 对齐对象：Web 首页信息流切换 + 评论弹层；Web 订阅详情抽屉的赞 / 藏 / 评。

6. 充提记录状态色 改

  • 列表支出金额（如 -200.00）浅色下须与账变支出、本页「本月提现」同红 #b91c1c，不得再停在 #FCA5A5。
  • 「已到账」：深绿字 + 浅绿底（对齐账变 .status.ok）。
  • 「入账中」：深琥珀字 + 浅琥珀底（对齐账变 .status.pending）。
  • 暗色标签也改为与账变同一套（绿 / 琥珀），不再用浅蓝 / 浅黄字。

8. 下线「暂时隐藏账户」 删

  • Web 隐私设置「你的数据」去掉「暂时隐藏账户 / 隐藏 30 天 / 暂时隐藏」整行。
  • 保留「导出我的数据」「永久删除账户」。

9. Web 侧栏收入芯片 改

  • .chip--income-month（如 +298.4 USDT）浅色下须可读：深琥珀 #92400E + 浅琥珀底。
  • 色值写在收入芯片自身，并在浅色主题变量中重映射 --warning-light，避免只改一处、别处仍浅金。
  • 悬停提示条保持深底白字。
