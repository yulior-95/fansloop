5. 后台链上充提网络与手续费 新

原 network-fees.html 仅 2 行场景费率；本期改为 USDT / USDC × 多网络 配置中心，并按 Ant Design 企业后台做高保真。

5.1 业务能力

  • 资产：USDT、USDC；网络：TRC20 / ERC20 / BEP20 / Polygon / Solana 等（可增删）
  • 每网络独立：充值地址、提现地址、充值手续费、提现手续费（固定费 / 百分比 + 最低费）
  • 支持上传或填写 URL 的充值二维码、提现二维码
  • 启用开关、排序、查询筛选、谷歌验证后保存/删除

5.2 高保真 UI（相对 7/29 通用后台表）

  • 顶部 Statistic 概览（USDT/USDC 网络数、启用/停用）
  • 带标签 Filter 工具栏；列表左右冻结列；资产徽章；手续费 Tag；二维码悬停预览；地址一键复制
  • 编辑弹窗分区：基础信息 → 地址 → 充/提手续费 → 二维码；Select/Input 走 Ant Design 增强控件

5.3 数据

  • js-web/fee-config.js → fl_fee_config_v2；可从 v1 scenes 迁移
  • 样式：admin-prototype/css/network-fees.css
