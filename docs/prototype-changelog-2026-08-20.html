1. 本次主题

8/18 仍是四步向导、封面 URL + 单视频。8/20 把创建收成一页平铺，类型增加「图视作品包」，素材支持多张写真与多个视频。后台审核在弹窗里看完全部媒体再通过 / 驳回；管理页只保留上架 / 下架，并区分普通下架与强制下架。

2. C 端创建页 改

  • 去掉页头说明文案（不再出现 PPV 边界长句）
  • 去掉步骤条与上一步 / 下一步；类型、素材、售卖、版权勾选同页提交
  • 商品类型三选一：图片合集 / 视频作品 / 图视作品包
  • 素材：必填一张首图；写真可多张上传或粘贴 URL；视频可多个 URL 并在格子里预览
  • 校验：图片合集至少 1 张图（无写真则用首图）；视频作品至少 1 个视频；图视包至少 1 张图 + 1 个视频

3. 橱窗编辑 改

  • 「编辑」只改标题、简介、价格、首图、个数，不可改上架状态
  • 上架 / 下架仍用卡片或详情底部按钮
  • 若运营已强制下架：不显示创作者「上架」，提示需等待运营核实后再强制上架

4. 数据模型

  • assetType 增加 bundle（图视作品包）
  • contentFiles[] 统一为 { kind: 'image'|'video', url }；历史字符串 URL 按后缀 / 域名推断
  • 每个商品已有唯一 id（如 da_seed_img_01），列表展示并可搜索
  • 新增 forceDelisted：运营强制下架后为 true，创作者 relist 被拒绝；运营「强制上架」清掉该标记
  • 订单已有 feePercent：成交当时的平台抽成比例，列表展示「平台 x% / 创作者 y%」

5. 后台 · 审核 改

  • 去掉顶部说明卡片
  • 搜索：商品 ID / 标题 / 创作者
  • 列：商品 ID、首图、商品、创作者、价格、总量 / 已售 / 剩余、通过后、提交时间、操作
  • 操作改为「审核」：弹窗展示全部写真（图）与视频（可播放），再点通过或驳回
  • 控件使用 Ant Design 的 Card / Table / Input / Button / Tag / Modal 样式，便于迁 React / Vue

6. 后台 · 管理 新

  • 本页只处理已通过审核的货架商品，状态筛选仅 已上架 / 已下架（待审、草稿、驳回不出现）
  • 售罄在本页仍记为已上架
  • 操作：
    • 详情：与审核弹窗相同，看全部图片和视频
    • 下架：效果同创作者下架，用户仍可自行上架
    • 强制下架：风控下架，forceDelisted=true，创作者不可上架
    • 强制上架：运营核实后上架并解除强制标记

7. 后台 · 销售记录 改

  • 增加商品 ID 列与搜索（订单号 / 商品 ID / 标题）
  • 「创作者实得」旁增加分成比例：记录下单当时配置（默认平台 10% / 创作者 90%）

9. 验收路径

  1. 创建页无步骤条、无 PPV 说明；可选图视作品包；上传 2 张写真 + 1 个视频 URL 后能提交
  2. 橱窗点「编辑」看不到上架状态下拉；上下架仍用卡片按钮
  3. 后台审核：搜索 ID；点「审核」能播视频、看写真，再通过
  4. 管理页无待审行；对已上架点「强制下架」后，创作者橱窗不能点上架；运营「强制上架」后恢复
  5. 普通「下架」后创作者仍可自行上架
  6. 销售记录能看到商品 ID 与「平台 10% / 创作者 90%」
