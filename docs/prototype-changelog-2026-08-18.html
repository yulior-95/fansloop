2. 数字商品 ≠ PPV 澄清

  • 数字商品：橱窗 / Creator Store 售卖的图片或视频 SKU，走四步创建 → 审核 → 上架购买
  • PPV：内容流发帖里的单篇付费解锁（已在 create.html 实现），与数字商品模块分离
  • 曾短暂按 OnlyFans 发帖 / Vault / PPV 改过创建页，已全部撤回；创建入口仍是 create-digital-asset.html 四步向导

3. 侧栏：保持「我的主页」 改

8/12 未约定橱窗链路的菜单高亮。本期约定：从个人主页点「我的橱窗」进入后的整条链路，侧栏始终选中「我的主页」，而不是「创建内容」。

  • 适用范围：creator-showcase、create-digital-asset、affiliate-catalog、digital-asset-store、digital-asset-detail、my-digital-assets
  • 实现：读取进入时的 nav 上下文；取不到时兜底 profile
  • 若从「创建内容」进入橱窗，则继续高亮「创建内容」
  • 顺带修复：侧栏缓存不再把上一页残留的 .active 带到当前页

4. 创建：一张首图即可 改

8/12 第 2 步是「封面 URL + 合集多图 URL 列表」。本期去掉合集清单和「设为首图」：图片商品只上传 / 粘贴一张首图，该图同时作为列表封面和购买后交付内容。

  1. 本地上传（原型压缩后写入 coverUrl）或粘贴图片 URL
  2. 1:1 预览；可移除后重选
  3. 视频作品：首图 + 视频 URL（封面仍只要一张）

确认页素材文案：图片「首图 1 张」；视频「首图 + 视频 1 个」。

5. 创建：商品个数与上架状态 新

8/12 第 3 步只有价格 + 限量/无限发行数量。本期售卖设置拆成三块：

字段选项说明
价格USDT与 8/12 相同
商品个数限量 / 不限个数限量须填可售份数，售完自动「已售罄」
上架状态上架 / 下架指审核通过后的状态；提交后一律先「待审核」
  • 上架：通过后立即出现在橱窗与 Creator Store，访客可买
  • 下架：通过后保持 delisted，创作者在橱窗点「上架」后再卖
  • 通过后仍可在橱窗 / 编辑里随时切换上架、下架，也可改可售份数（不得小于已售）

6. 数据模型

  • 沿用 fl_digital_assets_v7；assetType 仍仅 image / video
  • 新增 autoList：true = 通过后上架；false = 通过后下架。老数据缺省视为 true
  • 状态机：draft → pending_review → listed | delisted | rejected；限量售罄 → sold_out；橱窗可 listed ↔ delisted
  • 图片新商品：contentFiles = [coverUrl]（一张首图）

规格：commerce-dual-mall-spec.html 已写入 autoList 与状态机。

9. 验收路径

  1. 个人主页 →「我的橱窗 · n」→ 创建数字商品：侧栏一直是「我的主页」，不是「创建内容」
  2. 图片商品：只设一张首图即可下一步；无合集 URL 列表、无「设为首图」
  3. 第 3 步可选限量 100 份 +「下架」；确认页能看到个数与「审核通过后保持下架」
  4. 提交后进审核队列；运营可见商品个数与「通过后：下架」；点通过后橱窗为已下架，创作者再点「上架」才可售
  5. 内容流发帖 PPV 仍走 create.html，文案不与数字商品混用
