1. 运营后台 · 系统设置 RBAC

页面： admin-prototype/settings-roles.html · settings-members.html · settings-operation-logs.html

新增脚本/样式： js/settings-rbac.js · settings-roles-page.js · settings-members-page.js · settings-operation-logs-page.js · css/settings-rbac.css

平铺预览： admin-prototype/index.html（三页 iframe + UX 说明文档）

角色管理

  • 列表：角色名称、创建时间、更新时间、操作
  • 新建/编辑弹窗：三级权限树（一级菜单 → 二级菜单 → 功能操作）、备注、全选/全不选
  • 内置「超级管理员」不可删改权限
  • 保存权限需谷歌验证（TOTP）

成员账号

  • 列表：序号、头像、账号、邮箱、角色标签、状态、绑定 IP、最后登录
  • 新建/编辑合并角色分配：账号*、IP*、角色*、状态*、邮箱/显示名选填
  • 创建时自动分配 TOTP 密钥，无需邮件邀请；超级管理员可查看谷歌密钥
  • 禁用/编辑等敏感操作需谷歌验证

操作日志

  • 按一级模块、结果筛选；详情展示 Request ID、UA、变更快照 JSON

原型会话

admin-session.js 支持角色切换（活动运营 / 研发 / 超级管理员），Header 用户名随角色标签同步。

2. 运营后台 · 用户列表

页面： admin-prototype/users-list.html · 新增 js/users-list-page.js

列表

  • 筛选：UID/昵称、邮箱、钱包地址、账号状态、KYC 状态
  • 列：UID、昵称、用户名、邮箱、KYC、邀请码、更新时间、注册时间、注册地、注册 IP、账号状态、钱包状态、操作
  • 宽表横向滚动；UID + 昵称左固定、操作列右固定
  • 移除页面描述、导出按钮、批量勾选列
  • UID 蓝色可点（.js-uid-link）

用户详情弹窗（宽屏 Modal）

  • 顶部快捷操作：禁用账号、禁用钱包、KYC 认证、强制下线、重置支付密码
  • Tab：基本信息 / 账变记录 / 登录日志 / 操作记录
  • 基本信息：昵称、用户名、邮箱（修改/绑定）、邀请码、支付密码、钱包状态、注册信息等表格展示
  • 账变记录：全部/积分/充值/提现子 Tab；时间、类型、币种、变动（红绿）、余额快照、关联单号
  • 强制下线改用全局轻提示 AdminModal.notify("已强制下线")
  • 重置支付密码：两步（输入+确认 6 位数字 → 谷歌验证）

代用户 KYC 认证

  • 与用户端流程字段一致：钱包 zkMe / 证件+上传+人脸
  • 非简单备注框；含国家、证件类型、三格影像上传

行操作

  • 详情、禁用/启用账号、启用钱包；敏感操作需谷歌验证

导出 API：window.AdminUsersList = { openUserDetail, getUserByUid }，供全局 UID 链接复用。

4. 运营后台 · 弹窗与谷歌验证

文件： js/admin-modal.js · css/admin-modals.css

AdminModal 增强

  • 统一 Modal 壳层：遮罩、Esc 关闭、宽屏 fl-modal-wide
  • wireModalTabs：弹窗内 Tab 切换
  • notify()：顶部居中轻提示（成功/错误样式），不打断操作
  • confirmGoogle()：敏感操作 TOTP 二次验证；演示码 123456 始终通过

AdminGoogleAuth

  • 成员 TOTP 密钥生成与 localStorage 持久化
  • 修复「未绑定谷歌密钥」误报：getMemberAuth 按账号/邮箱查找

用户详情弹窗样式全局化

将原仅写在 users-list.html 内联的样式迁入 admin-modals.css，确保从用户资产等任意页面点击 UID 时，详情弹窗格式与用户列表完全一致：

  • .fl-modal-actions 顶部操作区
  • .fl-info-table 基本信息表格
  • .fl-ledger-tabs / .fl-ledger-table 账变子 Tab
  • .admin-kyc-* KYC 代认证表单与上传格
  • .pay-pwd-err 支付密码错误提示
